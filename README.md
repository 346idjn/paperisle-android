# 纸屿阅读（Android）

一款独立设计与实现的中文阅读器；名称、界面、文案、示例书目与代码均为原创。

## 版本 1.1.0

- **本地书架与分页阅读：**支持多选并依次导入 UTF-8 TXT/EPUB；EPUB XML/XHTML 兼容 UTF-8 BOM 和常见命名空间，提取章节文字、书目元数据及 EPUB 2/3 声明的栅格封面。封面缩小后显示在首页和书架；TXT 或无封面 EPUB 使用原创文字封面。支持搜索、标签、网格/列表、阅读进度与轻扫翻页。
- **书籍详情与阅读档案：**每本书可查看、编辑书名、作者、分类、标签、状态；详情记录正文字符数、排版页数、进度、累计/当日阅读时长、最近阅读时间、笔记数和书签数，并展示 EPUB 出版社、出版时间、语言、主题、简介及章节数。
- **章节目录与定位：**导入 EPUB 时保存 spine 章节标题及正文字符偏移；旧书和 TXT 尝试从常见章节标题生成目录。目录项可直接跳到对应正文页。修改字号、行距或页边距时，以当前正文字符位置为锚点重新分页，不再因为按百分比恢复而跳到别处。
- **仿真翻页：**加入真正运行的 3D 单页卷页动画，可在阅读设置中选择仿真翻页或平移滑动，并调节动画速度；菜单显隐不改变分页和正文位置。
- **沉浸式阅读菜单：**顶部提供返回、目录、分享、书签与更多操作；底部五项工具栏为目录、摘录、进度、主题和文字。目录、阅读进度和主题以可纵向滚动的底部面板打开，文字设置面板保留字号、行距、留白、字体、配色等选项。
- **滑块与触摸优化：**设置面板支持上下滑动浏览；横向滑块不会把纵向手势转成翻页，拖动时不逐帧重排，松手后再更新排版并保持当前阅读锚点。阅读页的进度滑块移入独立面板，减少误触。
- **返回与输入法：**Android 返回键、阅读页返回按钮、目录/主题/设置面板共用关闭优先、再回到进入来源的导航逻辑。Android 窗口启用 `adjustResize`，WebView 面板跟随可视视口变化，输入字段聚焦时自动滚入可见区域。
- **页面安全区：**支持状态栏、刘海/挖孔与底部手势区 Insets；阅读页可隐藏系统状态栏，工具栏与角标仍避让安全区域。菜单隐藏后页码和时间默认显示于页面顶部。
- **书签、笔记与统计：**支持页内书签、摘录、高亮、想法、问题和摘要笔记，多种高亮颜色、文本分享/图片卡片；含每日分钟/字数目标、年度完读目标、阅读时段分布、年度热力图与单书时长排行。
- **系统与在线朗读：**系统离线 TTS 从当前页开始，合并视觉换行后按标点拆句，预载多个短句并在到页尾时自动翻页；Azure Speech/自定义 HTTPS 音频接口可通过 Android 前台媒体服务后台播放。
- **手动跨设备同步：**WebDAV 可同步书籍、阅读进度、笔记、目标、统计、阅读样式和书签。AI 摘要及其设置入口已移除；升级启动时会清理旧版本机 AI 配置和已保存密钥。

阅读字数按停留至少 12 秒的已读分页估算，并尽量避免同一天重复计算同一页；属于阅读量近似值，不是精确分词统计。

## 在线服务配置与数据流向

Azure 语音需要用户自己的区域、语音名与 Speech Key；自定义 TTS 使用 HTTPS `POST`，请求 JSON 为 `{"text":"…","voice":"…","format":"mp3"}`，响应应为音频二进制。WebDAV 需要用户提供单个 JSON 文件的 HTTPS 地址、用户名和密码；服务器目录应预先存在，并支持 Basic Auth、GET 和 PUT。应用仅在用户手动点“立即同步”时传输书库。

未配置在线服务时，书籍与记录默认只保存在本机。启用 WebDAV 会把本地书籍全文、笔记、阅读记录、自定义阅读样式与书签写入用户填写的服务器。Azure、自定义 TTS 与 WebDAV 凭据使用 Android Keystore 的 AES-GCM 密钥加密保存；网络接口只接受 HTTPS。Android 自动备份默认关闭。

## 支持边界与构建

EPUB 导入提取章节文字，不保留原版式、正文图片或复杂排版；封面仅识别 EPUB 2/3 标准声明或文件名包含 cover 的栅格图片，单封面经压缩后保存在本机书籍数据中。不支持 DRM EPUB 或 PDF。单本最多 35 万字，TXT 文件上限 2 MB，EPUB 文件上限 12 MB。离线朗读依赖设备已安装的中文 TTS 引擎；若未安装，应用会提示打开系统语音数据安装页面。

需要 JDK 17+ 与 Android SDK 35：

```sh
./gradlew assembleDebug
```

APK 输出于 `app/build/outputs/apk/debug/app-debug.apk`。应用包名为 `app.paperisle.reader`，最低支持 Android 7.0（API 24）。
